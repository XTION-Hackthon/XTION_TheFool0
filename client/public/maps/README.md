# 地图图片目录

这个文件夹用于存放游戏地图的背景图片。

## 使用方法

1. 将地图图片放到这个文件夹
2. 主大厅地图命名为：`MainHall.png` 或 `MainHall.jpg`
3. 推荐尺寸：1600x900 或更大（会自动缩放适配）
4. 支持格式：PNG、JPG

## 当前地图

- `MainHall.png` - 主大厅地图

## 切换地图

要使用不同的地图，只需：
1. 把新地图图片放到这个文件夹
2. 命名为 `MainHall.png`（或在 `client/src/game/BootScene.ts` 里修改文件名）
3. 刷新浏览器即可

如果没有图片文件，系统会自动使用程序生成的深蓝色网格背景。
